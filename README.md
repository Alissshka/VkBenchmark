# VK Benchmark Automation

Инструмент на C# для автоматизированного запуска Black Myth: Wukong Benchmark Tool в двух режимах: CPU-тест и GPU-тест.

## Что делает

1. Собирает характеристики ПК (CPU, GPU, RAM).
2. Применяет настройки графики для **CPU-теста** (максимум нагрузки на процессор, минимум — на видеокарту).
3. Запускает бенчмарк, эмулирует нажатие Enter для старта теста, ждёт завершения.
4. Читает результат из конфига (`LastCPUBenchmarkResult`).
5. Повторяет то же самое для **GPU-теста** (максимум нагрузки на видеокарту).
6. Выводит итоговый отчёт.

## Как работает

Инструмент управляет настройками бенчмарка через конфигурационный файл:
<папка бенчмарка>\b1\Saved\Config\Windows\GameUserSettings.ini

В секции `[ScalabilityGroups]` меняются параметры `sg.*`, отвечающие за качество графики.

**Настройки для CPU-теста:**
- Разрешение: 25%
- Тени, сглаживание, постобработка, отражения, текстуры, эффекты, шейдинг: 0 (минимум)
- Трассировка лучей: выключена
- Дальность прорисовки и плотность растительности: 3 (максимум) — нагружают CPU

**Настройки для GPU-теста:**
- Разрешение: 100%
- Все параметры: 3 (максимум)
- Трассировка лучей: включена

## Требования

- Windows 10/11
- .NET 7.0 SDK или выше
- Установленный Black Myth: Wukong Benchmark Tool (Steam)
- Пакет `System.Management` (устанавливается через NuGet)

## Запуск

1. Открой `Program.cs`, замени путь в переменной `BenchmarkFolder` на свой.
2. Запусти бенчмарк вручную один раз, чтобы создался конфиг `GameUserSettings.ini`.
3. Выполни: dotnet run


## Почему выбран такой подход

Прямое управление конфигом — самый надёжный способ автоматизации бенчмарка:
- Не зависит от разрешения экрана и положения элементов меню.
- Не требует эмуляции кликов мышью.
- Позволяет точно задать нужные параметры графики.

## Примечание

Параметр `sg.ResolutionQuality` игра может перезаписывать при запуске на основе текущего разрешения экрана — это штатное поведение бенчмарка. Остальные настройки применяются корректно.
